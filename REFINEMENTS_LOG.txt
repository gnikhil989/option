ISSUE #4: Whipsaw Trading (Most Critical)
================================================================================
PROBLEM:
- Trades lasting only 2-8 seconds
- 20+ trades in 7 minutes
- Constant signal flipping between BUY CALL and BUY PUT
- Small losses + brokerage = significant loss

EXAMPLE FROM LOGS:
| Trade ID     | Duration | Exit Reason          | PnL    |
|--------------|----------|----------------------|--------|
| TRD_c7f39280 | 4 sec    | SIGNAL LOST          | -62.50 |
| TRD_bb96f0e1 | 36 sec   | SIGNAL LOST          | -50.00 |
| TRD_82d871dc | 8 sec    | SIGNAL LOST          | -12.50 |
| TRD_0eb8ad07 | 2 sec    | SIGNAL LOST          | 0.00   |
| TRD_e0114e73 | 2 sec    | SIGNAL FLIP          | 0.00   |

ROOT CAUSES:
1. No minimum hold time - exits after 1-2 seconds
2. No signal confirmation - enters instantly on any signal
3. Signals too sensitive to noise
4. Low cooldown (5 seconds)

FILTER DETAILS:

1. MINIMUM HOLD TIME (30 seconds)
   - Location: Exit logic (lines ~871-885)
   - Effect: Ignores "SIGNAL LOST (Neutral)" during first 30 seconds
   - Exception: SL/Target/Signal Flip still exit immediately

2. SIGNAL CONFIRMATION (10 seconds)
   - Location: Entry logic (lines ~983-1005)
   - Flow:
     a. Signal appears (e.g., "BUY CALL")
     b. Start 10-second timer
     c. If signal persists for 10s → ENTER
     d. If signal changes → Reset timer, start over

3. SCORE THRESHOLD (±15)
   - Location: Entry logic (lines ~976-981)
   - Effect: Only trades with |score| >= 15 are considered
   - Weak signals (score 4, 6, 13) are ignored

4. COOLDOWN DURATION
   - Normal Exit: 30 seconds cooldown
   - Signal Flip: 10 seconds cooldown (shorter since direction confirmed)
   - Location: Exit logic (lines ~949-956)
